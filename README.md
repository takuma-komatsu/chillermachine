# chillermachine

Endless ambient music generated in your browser with Web Audio. Each track explores a different mood and sound palette. No account, audio files, or server is needed.

Live site: https://takuma-komatsu.github.io/chillermachine/

## Run locally

Requires a recent Node.js version (20.19+ or 22.12+).

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, then press Play to start audio. Browsers require this first interaction before they can play sound. Use Next Track to generate another ambient piece and the volume control to set the level.

```sh
npm run build
npm test
```
